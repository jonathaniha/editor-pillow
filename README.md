# Simple Image Editor with Pillow

A Python-based desktop image manipulation utility that allows users to load, inspect, and apply visual transformations and filters to image files.

## Features

- Image file loading and directory browsing.
- Basic image transformations: rotation, flipping, and grayscale conversion.
- Modular image processing design (`ImageProcessor`).

## Technologies & Dependencies

- **Language:** Python 3.x
- **Libraries:** [Pillow (PIL Fork)](https://pillow.readthedocs.io/)

## Installation and Execution

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jonathaniha/editor-pillow.git](https://github.com/jonathaniha/editor-pillow.git)
   cd editor-pillow
   ```

2. **Install dependencies:**
   ```bash
   pip install pillow
   ```

3. **Run the script:**
   ```bash
   python EditorSimpleP4.py
   ```
